Internal targeting-segment API: playground

Everything on this page calls the real API. Each visitor gets an isolated sandbox with server-issued identities, and the role switcher only swaps which server-issued token is used. Buttons stay enabled for every role on purpose, so you can watch the server refuse a request a role isn't allowed to make. All traffic is a synthetic, seeded sample of 20,000 ad opportunities.

③ Publish

The server requires the simulation ID, the expected active version, and an acknowledgement for every warn-level warning. If the draft has changed since this simulation, the server returns 409 SIMULATION_STALE.
This is what an ad-serving component sends. Evaluator tokens get coarse reason codes only. Per-condition traces (?debug=true) need the editor's evaluate:trace scope, which shows privileged debug output being kept out of serving responses.
